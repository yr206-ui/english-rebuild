# English Rebuild · 英语重建

面向有阅读基础、实际听说薄弱的学习者：12周、84天，中英双语，日常交流与AI / ML科研英语并重，每日60–120分钟。

## 使用

下载仓库 ZIP 并解压，双击 `index.html`，无需安装依赖。或解压 `英语学习离线包.zip`。`教材.html` 为完整静态教材，可用浏览器打印为PDF。

每周包含一套双语生活对话、科研短文、8个词汇与理解题，七天分别训练理解、句型拼写、听力复述、生活口语、科研表达、综合输出和周测。84天是围绕12组核心材料的递进训练，不是84套不同对话。

## 功能与限制

- 响应式课程导航、84课任务与参考答案、拼写检查。
- 进度和笔记存于浏览器 localStorage，支持JSON导出与恢复。更换设备或文件位置前请备份。
- 听力使用浏览器合成语音；离线播放依赖设备已安装英语语音包，不包含真人录音。
- 口语需自行录音、自评，没有自动语音评分。
- 实验数字与研究场景均为教学示例，不代表真实论文或实验结果。
- 教材由AI辅助编写，欢迎提交纠错；不保证特定考试分数或语言等级。

## 开发

纯HTML和JavaScript，无构建步骤。`course-data.js`保存12周材料，`course.js`实现逐日任务和练习，`index.html`为入口。请同时更新离线教材和压缩包，避免版本不一致。

## 隐私

网站没有后端、统计追踪或云同步；学习记录仅存于当前浏览器。请勿提交个人笔记、进度备份或凭据。
